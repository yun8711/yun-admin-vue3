# yun-admin-vue3

Vue3 后台管理系统模板，技术栈：Vue 3.5+、TypeScript、Element Plus、Vite、yun-elp、SCSS、UnoCSS、VueUse。

## 环境要求

- Node.js >= 20
- pnpm >= 9（本项目仅支持 pnpm，使用 npm/yarn 安装将报错）

## 快速开始

```bash
pnpm install
pnpm dev
```

## 代码质量

- **Lint**：`pnpm run lint` / `pnpm run lint:fix`（oxlint）
- **Format**：`pnpm run fmt` / `pnpm run fmt:check`（oxfmt）
- **Style**：`pnpm run stylelint` / `pnpm run stylelint:fix`（stylelint）
